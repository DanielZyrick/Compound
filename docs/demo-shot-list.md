# Compound demo video: short shot list (Try the demo)

About 2½ minutes. A shorter alternative to [demo-script.md](demo-script.md): it records almost everything with **Try the demo**, so there's no account to prepare. The longer script covers more (Schedule, Contacts, About you, the phone view) with your own account or `npm run demo:seed`.

## Before you record

- [ ] **Browser:** a private window, about 1280×800 (or 1920×1080 at 110–125% zoom), no bookmarks bar, other tabs closed, notifications off.
- [ ] **Accounts:** record with **Try the demo** for everything except scene 4. Demo accounts show *labelled example* AI content, so for the one real-AI moment use your own account with a skill-track lesson ready.
- [ ] **CI green:** scene 8 shows a green run in GitHub Actions. Check it first.
- [ ] **Dry run:** do one silent run, then record.
- [ ] **Tools (Windows):** the Snipping Tool's record mode, or Clipchamp (built in; trims and adds captions). Upload as unlisted on YouTube, or to Loom.
